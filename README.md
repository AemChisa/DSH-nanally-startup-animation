# 娜娜莉 · Nanally Theme for DeepSeek Harness

By 这这莉是猫不是虎

城市彩色线稿、旋转光点抛落、娜娜莉接硬币与反重力行走，最后化为取自画面颜色的星点，吸附到界面边框、按钮和文字，进入动态壁纸与半透明界面。

**V1.1.0 分享版**。保留最新版动画、居中的“欢迎回家，鉴定师！”、片尾约 1.7 秒音乐淡出。开场声音默认开启，可在开场按钮或“娜娜莉主题”设置中手动关闭；浏览器限制自动播放时可能需要手动打开声音。

## 适用版本

已验证 Windows 官方 DeepSeek Harness **0.2.1-rc.5**。其他版本可能改变界面结构，尚不保证兼容。它是 DSH 插件，需要先安装并正常运行 DSH 一次。主题不提供模型或 API Key。

## 方法一：在 DSH 中安装

1. 复制本仓库地址：https://github.com/AemChisa/DSH-nanally-startup-animation
2. 在 DSH 打开“插件”→“添加插件”，粘贴仓库地址并安装。
3. 若提示“立即启用”，点击启用，然后完全退出并重新启动 DSH。

安装后侧栏会出现“娜娜莉主题”，可调透明度、壁纸压暗、模糊和开场声音，也可以重播开场。卸载时，在 DSH 的插件页面找到“娜娜莉主题”并移除，再重开 DSH。GitHub 下载失败时可使用下面的压缩包方式。

## 方法二：Windows 双击安装和卸载

下载本仓库 ZIP 或作者提供的分享版 ZIP，**完整解压后**使用。先保存工作，从 DSH 托盘菜单完全退出程序，再双击 **一键安装.cmd**。找不到软件时会弹出文件选择框，选择自己的 DeepSeek Harness.exe。安装成功后重新打开 DSH。

卸载：完全退出 DSH，双击 **一键卸载.cmd**，再重新打开 DSH；也可以直接在 DSH 插件页面移除主题。无需以管理员身份运行，也不需要安装 Node.js。

安装器把主题复制到当前 Windows 用户的 %LOCALAPPDATA%\NanallyDSHTheme，之后移动或删除下载的解压文件夹不影响主题使用。若解压目录已经删除，可重新下载后运行卸载，或使用 DSH 插件页面。

### 安装器具体改什么

- 调用 DSH 自带的插件管理命令，只添加或移除 @local/dsh-nanally-theme；不替换 DSH 程序文件。
- 修改前，将当前配置中的 package.json、cordis.patch.yml 和已有锁定文件备份到主题专用目录的 backups 下。
- 不读取或打包账号密钥、聊天记录和用户工作区；不主动结束 DSH 进程。官方插件管理器可能更新自己的插件锁定与依赖文件。
- 卸载保留其他插件和主题设置，不把整份旧配置强行覆盖回来。素材缓存中被修改或不认识的文件，以及配置备份会保留。
- 安装前校验包内文件；这能发现下载损坏，不能替代核实下载来源。建议只从作者仓库或作者分享的版本获取。

任何插件都无法承诺所有软件版本和机器上绝无问题。若失败，保留窗口的错误提示，先在 DSH 插件页面停用本主题，并把 DSH 版本和错误发给作者；不要覆盖整个 .dsh 文件夹。

### 自定义 DSH 数据目录

通常无需操作，安装器遵循当前环境变量 DSH_HOME，否则使用当前用户的 ~/.dsh。若你的 DSH 配置了其他数据目录或非默认 profile，请让熟悉该配置的人指定安装参数；找不到有效配置时安装器会停止，不会擅自新建一个。高级参数示例见 installer.ps1 的参数定义（DshExe、DshHome、Profile、ManagedRoot）。

## 源码与重建

仓库根目录已包含可安装的 client.js，安装不需要构建、网络脚本或额外依赖。修改源码后，可在安装了 Node.js 的开发电脑上运行 **node build.mjs**，重建内嵌素材并更新校验清单。不要只修改 client.js 而忘记更新清单。

- src/client.template.js：动画播放、星点吸附和主题设置。
- src/theme.css：半透明界面与排版。
- assets/opening.mp4、assets/wallpaper.mp4：片头与循环壁纸源素材。
- tools/manager.cjs、installer.ps1：Windows 安装/卸载管理。
